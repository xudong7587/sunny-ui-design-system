# 1.0.2 柔软浮雕验证

日期：2026-10-09。环境：本机 Windows，Node 与本仓库锁定的 TypeScript/Vite，Codex 内置 Chromium 浏览器。

## 行为变化

- 单一 appearance 源码提供外层凸起、内层凹陷、输入与选择器凹陷、按钮按压和选中、深色轻柔高光；保留 `soft` ID 和旧公共材质变量。
- demo增加实际筛选、长记录、select、错误与禁用、状态提示和原生确认 dialog。均为本地演示交互。
- 设计规范、接入说明、Skill与用户偏好同步，发布包版本为1.0.2。未新增依赖。

## 实际通过

- 类型检查、类型声明输出、库构建、演示构建通过；使用 package.json 对应的 Node/TypeScript/Vite 命令直接执行。首次 pnpm 入口因自动依赖校验访问 registry 超时，随后使用已锁定的本地工具完成检查。
- soft＋奶霜花园，浅深两模式分别检查320、390、700、1360宽度：DOM文档无横向溢出。
- 320宽度下外观 dialog 可打开、滚动和关闭。选择材质、配色、明暗即时生效，刷新保留三项选择。
- 内层卡片与输入框实际computed style均为inset，外层为双向外阴影。检查中发现并修复旧公共选择器优先级覆盖。
- 输入文字与select选择可操作；Tab焦点显示主色实线轮廓。确认 dialog的确认可更新提示，Esc关闭后焦点返回打开按钮。
- 筛选待处理只显示相应记录，禁用按钮不可操作。提示至筛选、筛选至操作区约20px，不重叠；长名称在手机换行。
- 已查看实际浅深截图；深色高光经过收敛，截图保存于 `docs/images/soft-*.jpg`。

## 验证边界

本轮验证针对更新的soft材质与demo交互；没有重新穷举全部色彩×材质组合。减少动效、减少透明度与系统高对比度的CSS规则已检查，尚未在相应系统设置下实测。跨标签同步的实现未变，本轮未重测。MediaIndex宿主接入将在Git更新后的产品整改中验证，不能把独立demo结果当作全产品验收。
