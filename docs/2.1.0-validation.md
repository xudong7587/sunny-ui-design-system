- `pnpm typecheck`、`pnpm build`通过，生成ESM、类型和本地演示。依赖版本未更新。最初类型检查发现元组空值类型和SVG导入声明缺失，均修复后通过。
- 生成的preview.css SHA256仍为 `68be78a4117c003b1ba9ef7b9354a2de9c2787304035694a40f0d370f6ac7c60`。2496组原有明暗/材质/配色/圆角组合的普通面板、输入、按钮、内层卡片、body的8项计算样式与隔离基准相同。原始HTML本轮不可用，隔离基准使用指纹核验后的原始CSS；这不是重新访问原HTML的视觉验收。
- Microsoft Edge（Chromium）实际截图检查二维棋盘背景：折射与模糊回退在边缘采样区的通道平均差为11.73；前景纯白与黑色图形像素保持不变，改变实际DOM背景后能看到新颜色。初版仅用纵向条纹，无法检测顶部的纵向位移；改用二维图案，保留位移强度断言。

- 原生玻璃dialog外侧像素打开前后完全一致；圆润模式弹层圆角最多24px。Esc、四维持久化、跨标签、320/390/700/1440宽度、无横向溢出、强制颜色和无空闲帧循环检查通过，无页面异常。
- 自动模式的其他引擎回退只做了替代UA路径检查，未声称在实体Safari/Firefox逐项验证。Chromium外默认背景模糊；系统减少透明度或强制颜色时实色回退。
- 原有字体、材质预设和存储键未变。真实页面滤镜不采集截图或业务文本，Android版本要求不适用于网页。
