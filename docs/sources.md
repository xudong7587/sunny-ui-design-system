# 来源与许可

Sunny UI 2.0 的唯一视觉来源为用户指定的 MediaIndex-UI-Preview/index.html（2026-10-21 提取）。原始 CSS 完整保存在 skills/sunny-ui-design/assets/appearance/preview.css，材质样本、配色目录和圆角来自同一文件，指纹见 design-source.json。

旧 Sunny UI 仓库仅作为 React/Vite 工程与许可基础；其旧设计规则、示意图、主题实现不作为 2.0 的依据。没有复制 MediaIndex 后台、账户、业务 API 或本地调试身份。

README 截图来自该静态预览，全部海报、主视觉画面和缩略图经高斯模糊后保存。截图只说明设计，不代表实际 MediaIndex 业务已经完成或通过验收。
