# Sunny 的常用设计标准

本文件记录已明确表达的偏好，具体任务中的最新要求优先。

## 前端

注重质感、组合自由和可复用模块。外观选择把色彩、材质、明暗独立组合，立即生效；玻璃要有整体多层半透明，小卡片和控件不能停留在扁平默认样式。

主题色应明亮、有不同主色。多色以圆形渐变色盘展示，保留马卡龙等温和色系。各材质要有真实差异，不用多个近似方案凑数量。风格可以多样，以实际观感和可读性为标准；苹果风格不是唯一方向。

2026-10-09 用户明确喜欢柔软浮雕，并要求沉淀到 SunnyUI 供其他项目复用。标准是外层凸起、内层凹陷、主辅色轻染、双向柔影、深色柔光，以及完整的控件状态；具体令牌见设计规范。应用质感时保留产品原有导航与设置语义，重大结构调整先展示前后对照供用户确认。避免提示与操作区相压，文字清晰和实际易用同样属于交付标准。

主要交互标准参考 Emil Kowalski 的设计工程技能：反馈快速、动效有目的、节制的按压反馈、悬停能力判断、减弱动效支持。默认避开未经要求的大规模视觉重写。

紧凑手机导航留主 Logo 和右侧 4×2 图标即可，减少纵向空间占用；页面完整名称留在独立工具栏。

## PowerPoint（仅用于 PPT 任务）

用户长期标准是「质感 + 可组合 + 原生文字设计」：在品牌和模板基础上协调渐变、柔光、轻阴影、细描边与留白；按实际内容布局，不照抄参考几何。对象能组合与取消组合，清除生成对象禁止组合属性并按模块分组。普通文字为原生可编辑文字，使用自身原生阴影或发光，不以错位重复文字模拟效果。未指定字体且模板适用时，标题与模块名优先微软雅黑，说明与细节搭配华文楷体，协调字号间距。

这些是 PPT 的要求，不直接变成网页 DOM、字体或文字效果的强制规则。
