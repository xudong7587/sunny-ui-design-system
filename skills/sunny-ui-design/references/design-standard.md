# 配色与材质规范

## 组合模型

将主题拆成明暗模式、配色和材质三个维度。明暗改变基础阅读背景；配色提供主色、辅色和点缀；材质改变透明度、渐变、阴影、边缘和圆角。切换任何一项都不覆盖其他选择。

主色用于主要操作和选中态，辅色与点缀用于背景光、装饰和层次。成功、错误与警告由独立状态色表达。多色方案覆盖玫红、蓝、紫、青、薄荷绿、橙、金、红等主色，避免整个目录只有紫色的不同搭配。

用圆形锥形渐变展示色系：从顶部附近开始，主色、辅色、点缀按钟表方向交融并回到主色。单色使用圆点。

## 材质目录与重量

| 材质 | 表现 |
| --- | --- |
| 清晰默认 | 中性实色、轻边线、低阴影 |
| 纸页档案 | 暖纸底、细描边、浅压痕，深色对应暖灰纸面 |
| 极光玻璃 | 多色环境柔光透过半透明外层和内层，轻磨砂 |
| iOS 玻璃 | 更清透的磨砂面、亮边、悬浮阴影，背景可透入 |
| 柔软浮雕 | 柔和方向性明暗与浅浮雕，控件也有触感 |
| 精致描边 | 纤细轮廓与轻底部层次，少用大面积装饰 |
| 双色渐层 | 有方向的实色双色渐变，与玻璃保持明显差异 |
| 缎光瓷面 | 微亮曲面、细腻高光和柔阴影 |

外层面板、内层卡片、交互控件各自有权重变量：`--material-fill`、`--material-inner`、`--material-control`。共同使用边缘、阴影和磨砂参数，不把内层卡片强制恢复成扁平白块。玻璃需要实际半透明底色和背景内容；只有 blur 而背景全实色，看起来不会通透。

iOS 玻璃采用方向性高光渐变：外层保留清透中心与较亮边缘，内层卡片和控件各自拥有不同的反光重量；亮边、内侧反光与柔和投影一起表达厚度。极光采用约 40% 的半透明底与透明色光渐变叠加，明显重于 iOS。依据背景复杂度和文字对比度调整，文字本身保持实色。不要堆叠过多透明层与全屏滤镜，长列表里要控制磨砂范围。

## 布局与文字

根据内容结构决定分区，保留清晰标题、主操作和留白。普通说明色在深浅背景上都能阅读。正文优先系统字体与微软雅黑，避免超细字重、全页极小字号和长段紧凑文字。标题通常 24–32px，模块名 16–20px，正文 14–16px，辅助信息 12–13px，随密度调整。

颜色和质感不能改变业务信息的优先级。表单、表格和状态仍然清楚，主要操作避免被装饰色抢走。使用标准对比度判断；较亮主色的按钮自动使用深色文字。

## 交互

即时展示选中状态；按下反馈约 `scale(.97)`，普通反馈 120–220ms，通常少于 300ms。使用自定义 ease-out，列出具体 transition 属性。hover 只对支持悬停的细指针设备生效。快速切换不能等待前一次动画结束。

原生 dialog 用于模态选择，提供关闭按钮、Esc、语义标题及焦点恢复。键盘能操作，焦点稳定可见。尊重 `prefers-reduced-motion`、`prefers-reduced-transparency` 和系统高对比度；降低透明度时改用实色表面。

## 响应式验收

桌面保留完整导航和内容层次。紧凑手机导航可采用左侧主 Logo、右侧 4×2 图标，页面名只保留在下面工具栏。长标题可换行，不用导航遮挡标题；导航内部不出现无意义的滚动条。外观弹窗在手机中使用单列材质、双列配色，整体高度受视口限制并可滚动。

检查 320px、390px、700px 附近的宽度与普通桌面宽度。用真实页面验证标题、弹窗、长内容、按钮点击范围、横向溢出。检查每类材质的外层、小卡片和输入控件；检查浅深模式、刷新持久化、跨标签同步和未知旧偏好回退。新样式只覆盖明确组件，避免 `button` 全局规则抹掉危险操作、成功状态或当前选中样式。
